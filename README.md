# classCalendar Development Display

**classCalendar** is a completed student scheduling and productivity app.  
It was developed in **FlutterFlow (Dart)** with **Firebase** powering authentication, Firestore, and storage.  
The app was later packaged and published through the **Apple Developer Program**.  

---

## 📂 Features
- 📅 Schedule management for classes, tasks, and assignments  
- 👥 Friend system with add/remove requests and notifications  
- 💬 Chat with styled message bubbles, file & picture support  
- 🔔 Notifications for events, tasks, and friend activity  
- 📲 Multi-platform support (iOS via Apple Developer Program)  

---

## 🛠️ Development Notes
- Core stack: **Dart, FlutterFlow, Firebase**  
- Additional contributions in **Makefile, JavaScript, Ruby, HTML, Swift**  
- Active development continued until **January 2025**, after which the project was finalized.  
- This repo represents the **development codebase**; the production app was shipped externally.
